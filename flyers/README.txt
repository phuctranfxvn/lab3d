Đặt ảnh nền trong suốt (PNG/WebP/GIF/SVG) vào đây, ví dụ doraemon-left.gif, nobita.png.
Các hình sẽ cùng bay ngang nền trang chủ. Thư mục trống thì web dùng chong chóng tre mặc định.

Hướng bay: tên file có chữ "left" hoặc "trai" nghĩa là hình quay mặt sang trái.
- Mọi hình đều quay trái  -> cả nhóm bay từ phải sang trái.
- Còn lại                 -> cả nhóm bay từ trái sang phải, hình quay trái được lật lại.
